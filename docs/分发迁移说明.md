# 分发迁移说明

本包从两个当前功能分支的已跟踪源码复制，来源提交见 `DISTRIBUTION.json`。没有删除、移动或合并原项目的 Git 历史，也原工作区的本地素材直传优化同步到本包。它是源码分发副本，不是包含个人数据的全盘备份。

为在新电脑运行，副本增加以下迁移改动：

- 添加固定 Node 24.14.1、pnpm 10.33.0、依赖安装脚本；OSS SDK 为 --with-oss 可选项。
- `bin/hypit` 读取用户自己的 `.env.local`；`bin/replicate` 统一转到该入口，使子进程能继承配置。
- `packages/replication-workflow/src/plan.mjs` 从 `DISTRIBUTION.json` 记录原始源码来源，避免要求私有 Git 历史。实际实现文件和素材的指纹仍进入计划，用于提交边界核对；来源提交不代表分发修改已提交 GitHub。
- 免费测试入口设置明确的模拟密钥，仅满足无收费规划预检，不读取作者真实密钥；测试中的请求均为模拟或 localhost。
- H3 Runtime 改用用户环境凭据，移除个人 Chrome 路径和默认苍远线路。保留规划器需要的旧配置文件名。
- `hypit/packages/provider-cangyuan/runtime/oss_storage.py` 移除作者默认 Bucket，仅显式 OSS 线路需提供自有桶，官方 H3 默认不使用。
- `.agents/skills/hypit` 从目录内链接转为完整实体副本，保持上游内容一致，便于解压和 AI 读取。
- 根目录规则和使用说明改为下载用户版本；原工作区文件仅作为归档背景。保留完整上游许可证和版权。

不包含：原项目两份 `.git`、作者实际密钥和账户配置、历史任务/媒体、账本、缓存、虚拟环境、软件依赖、私人审查回执。上游源码自带的示例素材仍用于原版演示和测试，不是作者历史生产成果。原参考文件和历史验收未继承到新用户。

免费 Provider 测试原先依赖作者历史生产素材，改为临时合成有效图片/视频并保留原请求断言；本地渲染测试允许 `HYPIT_TEST_FONT_PATH`，Linux 默认采用 Liberation Sans。所有素材均为免费合成测试，不代表人物生成质量。

`docs/分发迁移修改.diff` 保存业务代码、OSS 默认值及测试素材的改动的前后差异。源码分发指南与配置改动以包内文件为准。后续新增模型应优先独立 Provider，并在明确授权下补充任务规划与收费保护；无需为推荐模型而改变当前 H3 工作流。
