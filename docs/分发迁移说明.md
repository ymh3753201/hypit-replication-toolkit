# 分发与版本来源

本包由两个独立开发仓库的已提交源码生成，来源提交记录在 DISTRIBUTION.json。公开仓库维护完整可下载源码，安装包按同一发布标签制作。

用户配置使用环境凭据模板。根目录 .env.example 提供空配置项，安装时由 AI 在本机写入自己的 .env.local 并设置权限。引擎使用包内 0.3.2，软件依赖按冻结锁文件安装。首次安装会选择包内 H3 Runtime，已有 Runtime 选择由用户继续管理。

上游制作技能保留原文，根目录 .agents 与 .claude 提供完整副本，便于 Codex 和 Claude Code 读取。scripts/install-skills.py 执行文件核对。

运行状态、个人任务、媒体、收费账本、密钥、已安装依赖及模型缓存由各自用户在本机管理。升级原有工作环境前，先备份并核对实际任务和结果。

许可证与版权信息位于根目录 LICENSE 和 hypit/LICENSE。首次安装与真实模型生成的检查范围分别记录在 安装包验证报告.md。
