# 0.1.5 发布说明

本版配套 Hypit 0.3.2，来源为官方 main 的 47bfe6e9。上游变更来自 hypit-ai/hypit，许可证和版权信息保留在 LICENSE 与 hypit/LICENSE。

制作层采用上游 0.3 的媒体处理、具名时间窗口、Visual/Audio Clip、Fine Text 和 HTML Video。业务层继续核对素材、预算、任务回执及审阅证据。完整制作技能随包提供，Codex 与 Claude Code 各 71 个文件。

旧版作品先备份任务、账本、原始结果、Runtime 和工作环境，再按 hypit/migrations/0.3.zh-CN.md 与 hypit/migrations/0.3.1.zh-CN.md 迁移需要继续编辑的文件。已生成的媒体可以通过明确的复用选择接入新作品。原任务编号继续用于查询原任务。

首次安装按根目录安装部署操作指南.md 执行。基础依赖需要联网下载，自己的 API 通过环境凭据模板配置。默认官方 H3 使用本地直传或同账号模型文件接口。

完整安装验证结果见根目录 安装包验证报告.md。
