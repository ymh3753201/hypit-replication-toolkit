# 0.2 作品的迁移与历史查询

0.1.5 配套 Hypit 0.3.2。已有 0.2 作品按引擎 migrations 目录中的中文指南迁移实际使用的语法，保留原媒体和结果。

升级前备份旧工具目录、任务、Runtime、结果和收费账本。历史完成结果可在原工具中 inspect/get，运行中的任务使用原 Runtime 和原编号查询。恢复查询与新的收费请求按原授权分别核对。

高级兼容入口 bin/hypit legacy 读取本机自行保留的 .toolchain/hypit-0.2.17 和 .hypit/compat/hypit-0.2.17.runtime.json。恢复这套环境时，从旧工具备份取出对应引擎与配置，使用旧锁文件安装依赖，并把配置的数据目录指向原任务数据。密钥继续通过自己的凭据存储读取。

若已有备份中的旧工具仍可使用，优先在原环境完成查询和导出，再将已有媒体显式接入新作品。
