# H3 复刻质量优化（本地开发版）

本版继承公开版 v0.1.3-students-20261003，并合并 Hypit 官方 v0.2.17。未改动上游制作 Skill、生成组件、Runtime 协议、剪辑和渲染算法。新增行为在现有二开 Provider、Prompt Kit、业务规划与审阅模块实现。没有新增模型服务或付费重试。

## 分镜与主体对应

任务继续使用 replication.task@1，旧任务字段保持兼容。新计划建议添加：

```json
{
  "captions": {"mode":"model", "description":"准确字幕内容、样式和出现时间"},
  "segments": [{
    "id":"s1", "duration":5,
    "shots":[{"id":"opening","start":0,"end":5,"subjects":["host","item"],"referenceIds":["person","product","source"],"direction":"保留原机位、人物位置、抬手节奏和持物关系，只修改指定人物与物品。"}]
  }]
}
```

这是字段片段，须合并到完整任务；不能直接作为 task.json 使用。shots 时间为当前输出片段内的秒数，必须按顺序覆盖完整片段。subjects 对应该片段要求中的 subject，referenceIds 必须已实际连接。空人物镜头可使用空 subjects，不能编造原视频未观察到的镜头。未提供 shots 的历史任务仍可读取，但人物替换计划会提示补齐。

实际提示词按 subject_definitions、summary、retention_analysis、detailed_description、overall_soundscape、non_diegetic_music 组织。同一主体标签和图片编号贯穿请求；中文台词与品牌文字原样保留。官方指南是方向建议，并非新的 API 字段或换脸保证。

图像来源继续优先使用可用的本机 Codex 生图技能，否则采用用户已配置且获预算授权的生图 API。需要保留构图时，从原片关键帧编辑人物/物品，保留原始肖像、商品图作依据。构图、角度、姿势、持物关系核对后可在图片素材声明：

```json
"sourceFrame":{"assetId":"source","time":2.5,"reviewedBy":"实际审阅者","compositionMatched":true}
```

原片时间必须落在真实视频内；参考视频模式下要实际连接该原片。此字段记录人工/AI 的审阅声明，不自动证明图片与原片一致，也不把普通参考图变成首帧或身份硬锁。不能填入未观察到的通过结论。程序会提示身份漂移风险，动态结果仍须逐项验收。

## 字幕责任

- model：在同次视频请求里生成指定字幕，剪辑拒绝再次叠加字幕。
- local：视频请求不生成字幕覆盖层，剪辑必须提供 layout.captions 和真实字体。
- none：不生成也不叠加字幕；商品本身的文字仍依照需求。
- 未填：沿用明确的任务方向，不再强行附加“精确字幕在本地合成”的冲突指令。

只写 mode 不足以保证字幕效果。模型字幕的错字、样式和时间仍需真实验收。

## 视频接收与尾部审阅

继承新版 0.5 秒接收容差。模型返回字节先保存到 Hypit 原生 ResourceStore，再验时长、分辨率、画幅。失败消息提供资源编号；受保护任务账本 output.artifact 保存资源引用和 SHA-256，仍保留官方任务编号及费用占用。检查失败不放行交付、不裁剪原件、不新增 POST。损坏文件也仅作为诊断原件，不能冒充有效视频。

请求与实际时长相差大于 0.3 秒时，模型审阅新增 timing 项，review-template 自动列出。带声音结果必须同时看画面并听音，覆盖完整原件，确认按计划剪辑不会裁掉必要台词或动作。偏短结果不能用 timing=pass 授权补帧，须重做剪辑计划。人物、物品、台词等其他验收项仍然独立生效。

超出 0.5 秒仍标为技术失败，但原件保留供诊断；恢复导出按 output.artifact 和对应 Runtime 的资源存储位置处理，不能伪造成功 Build。历史任务继续用原安装与原账本恢复，不能因升级重投。

## 开发与验证

外层业务仓库和 hypit/ 引擎仓库独立，均在 feature/h3-replication-quality-20261004。引擎历史从 b00532e 开始，先还原校验过的用户 0.1.3 扩展，再合并官方 v0.2.17。上游 remote 为 upstream，推送钩子阻止向官方推送；开发提交与公开发布分别核对；发布状态以仓库为准。

免费测试：bin/test-replication。可用 HYPIT_TEST_FONT_PATH 指定测试字体，HYPIT_TEST_RUNTIME 指定不含密钥的本机浏览器配置。scripts/test-upstream.mjs 按官方同一文件列表运行测试，并将并行数限制为 2；WSL 可设 COLUMNS=80 LINES=24，避免 ps 的终端尺寸警告干扰进程清理断言。

新增测试覆盖参考映射、镜头完整性、关键帧时间、字幕责任、时长偏差门禁及拒收原件保存。历史两份模型文件进行离线接收回放，所有 HTTP 均拦截，真实模型费用为 0。程序通过不代表模型已能稳定换人，仍需新的预算授权后做关键镜头实测。
